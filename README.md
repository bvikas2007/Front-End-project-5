# Responsive Portfolio Website

A clean and responsive personal portfolio website built using **HTML5** and **CSS3**. This project demonstrates the use of modern web development techniques such as Flexbox, CSS Grid, the Box Model, and Media Queries to create a layout that adapts seamlessly to different screen sizes.

## Features

- Responsive navigation bar
- Hero section with title and description
- Projects section
- Work Experience section
- Education section
- Teacher Reviews section
- Contact Form
- Responsive design for desktop, tablet, and mobile devices
- Clean typography and consistent color scheme
- Hover effects on navigation links and buttons

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries

## Responsive Design

The website is fully responsive and adapts to different screen sizes.

- Desktop Layout
  - Three-column content section
  - Horizontal navigation bar
  - Review cards displayed side by side

- Mobile Layout
  - Stacked sections
  - Vertical navigation
  - Review cards displayed one below another
  - Contact form optimized for smaller screens
